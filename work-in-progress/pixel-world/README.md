# Archived pixel-world source checkpoint

This preserves the original incomplete cross-chat source before integration. The working connected-world edition is now in [`../../public/world`](../../public/world), with 13 prepared landscapes, a complete manifest for the 55 existing illustrated residents, portrait search, signature effects and runtime tests.

Run the repository root with `npm run dev` or build it with `npm run build`. The default page opens the connected world; the previous illustrated viewer is `/illustrated.html`.

This archived standalone checkpoint is retained for provenance and is not the runnable entry point. Unique character action poses and expanded full-body coverage remain unfinished art-production work.
